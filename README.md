# USU Tuition Proposal Explained

An independent, student-made explainer of Utah State University's proposed fall 2027 tuition model.
Not affiliated with or endorsed by Utah State University.

**What's inside** (single page, no build step):

- **Overview**: what's proposed, who pays more or less, key dates
- **Your money**: enter your residency, credits, major and scholarship to see your bill today vs. proposed and where each dollar goes
- **By major**: the change in your bill for each major
- **College budgets**: 2026–27 college budgets and how much comes from differential tuition
- **Scholarships**: scholarship money by college and how each type of award interacts with the proposal
- **Take action**: decision timeline, public contacts, an email template
- **Sources & methods**: every source, plus what's verified vs. estimated

All figures come from public USU, USHE and Utah Legislature documents (linked on the Sources tab), current as of Nov 24, 2026.

## Hosting on GitHub Pages

1. Create a new public repository on GitHub.
2. Upload `index.html` and `README.md` to the root of the repository.
3. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.
